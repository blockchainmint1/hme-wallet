# Cash-out

- TSD cash-out key is profile-scoped (src/lib/cashout/api-key.ts): link claims write to the wallet captured before any await, records keep only an 8-hex fingerprint, the legacy device-wide key migrates once (marker; a reappearing unprefixed key is the default wallet's), and cash-out orders re-check wallet+key fingerprint before signing. Why: an account token must never cross wallets.
- Cash-out path is chosen by `chooseCashoutPath` (src/lib/cashout/one-time.ts): only a payout equal to the account's saved address uses the permanent inbox; any other address is a one-time `/cashout/orders` order. Its refund address is the Omni sender (`pickOmniSender`, same rule as the send) and the send refuses a different sender; the reply is verified (fresh legacy T… deposit, not the permanent inbox or a wallet-owned address, echoed account inbox agrees, echoed payout, exact decimal amount, Ethereum, `ONE_TIME_EXPIRY_MARGIN_MS` left). Right before signing the wallet re-polls the order (or re-reads the saved address on the inbox path); the deposit notice is sent only for the permanent inbox. `/cashout/payout-address` is a separate explicit action and never precedes a deposit. Why: the permanent inbox always pays the saved address, a missing refund address defaults to that inbox, and TSD Swap only accepts notices for it.
