# Security policy

Honest Money is a self-custodial wallet. Your reports help keep members' funds safe.

## Reporting a vulnerability

Email **help@honest.money** with:

- what you found and which build it affects (website at mobile.honest.money, Android app, or Chrome extension, with the version number),
- steps to reproduce,
- what an attacker could do with it.

Please **do not** open a public GitHub issue, post exploit details, or share them anywhere public until we have released a fix.

**Never send recovery phrases, private keys, passwords or real wallet backups** — not yours, not anyone's. We will never ask for them.

## What to expect

- We read every report and reply to confirm we received it.
- We work on confirmed issues privately and tell you when the fix ships.
- With your permission, we credit you once the fix is live.

## In scope

- This wallet's code in this repository: web, Android (APK) and Chrome extension builds.
- Its server functions and public endpoints under mobile.honest.money.

Issues in third-party services (block explorers, swap providers, indexers) should go to those services; tell us too if they affect our members.

## Supported versions

Only the latest released website, Android app and Chrome extension receive security fixes. Installed apps are prompted to update.
